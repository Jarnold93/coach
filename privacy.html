Coach: privacy

Coach is a personal training and nutrition app used by one person, its owner.

Google Calendar: Coach reads the owner's calendars read-only, to see when meetings are scheduled. It stores only each meeting's start time, end time and title, in the owner's private GitHub repository, to plan the day around them. It never changes, shares or sells calendar data, and it uses no other Google data.

Other data: logs, photos and settings stay on the owner's phone and in the owner's private GitHub repository. Meal photos and questions are sent to Anthropic's Claude API only when the owner asks for an estimate or advice.

To revoke access at any time, go to myaccount.google.com → Security → Third-party connections → Coach → Remove access.
